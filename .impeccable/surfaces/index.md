# Surface: Get to 1 second (index)

## Mode

Experience

## Scope

Single-page hold-to-run timing game: title, millisecond readout, one Hold control, result feedback, confetti on exact 1.000s.

## Audience & job

Casual browser players killing a minute; press, release near 1.000, try again.

## Direction contract

THESIS: The page is one kitchen egg timer — hold winds time, release freezes the dial; exact 1.000 earns confetti. Refuses the centered-title-plus-blue-button microgame template.

OWN-WORLD: Soft sage countertop ground (#c8d4c0), cream enamel dial (#f0e6d8), tomato-red stem (#e23a2e), ink face (#2a2e2c). Chrome rim, tick marks, red second hand. Display face Bricolage Grotesque; UI Figtree. One circular silhouette owns the viewport; no cards.

STORY: Visitor understands “hold, release at one second,” believes milliseconds matter, acts by pressing the stem (mouse or any key).

FIRST VIEWPORT: Giant dial centered; title on the face; tabular readout dead-center; red hand sweeps while held; fat Hold stem under the rim; short hint below. Matches assigned.html sketch.

FORM: Kitchen egg timer (grounded list #7, assigned). seed:1626e34ca99857e6

## Signature interaction

Hold (pointer down / key down) starts the millisecond clock and sweeps the hand; release freezes; near-miss shows delta; exact 1.000 fires confetti.js; readout scale swells toward 1s then snaps on stop.
